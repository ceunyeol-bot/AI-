홈페이지 제작

지금 여러분이 보고 있는 이 교육 사이트도 AI와 함께 만든 홈페이지입니다. 코딩을 몰라도 괜찮습니다. 노코드 툴과 AI 코딩 어시스턴트, 두 가지 방법으로 나만의 홈페이지를 만드는 법을 배워봅시다.

🎯 이번 챕터 학습목표

  • 노코드 제작과 AI 코딩 제작 방식의 차이를 이해한다
  • 대표적인 노코드 홈페이지 제작 툴을 안다
  • AI 코딩 어시스턴트에게 프롬프트로 홈페이지를 요청하는 법을 익힌다
  • 도메인과 호스팅의 기본 개념을 이해한다

1. 제작 방식 비교: 노코드 vs AI 코딩

🧩 노코드 툴 (드래그 앤 드롭)

  • 미리 만들어진 템플릿에 내용만 채우는 방식
  • 배우는 데 시간이 거의 안 걸림
  • 디자인 자유도는 다소 제한적
  • 대부분 자체 호스팅까지 한 번에 해결

🤖 AI 코딩 어시스턴트

  • 원하는 내용을 말로 설명하면 AI가 실제 코드(HTML/CSS 등)를 작성
  • 디자인·구조를 훨씬 자유롭게 원하는 대로 조정 가능
  • 완성된 코드를 호스팅 서비스에 직접 올려야 함
  • 이 교육 사이트도 이 방식으로 제작됨

빠르고 간단하게 시작하고 싶다면 노코드 툴을, 나만의 개성 있는 결과물과 자유도를 원한다면 AI 코딩 어시스턴트를 추천합니다.

2. 대표적인 노코드 홈페이지 제작 툴

툴특징추천 대상
미리캔버스 / 캔바디자인 템플릿 기반, 간단한 소개 페이지 제작에 특화디자인 감각을 살려 빠르게 만들고 싶은 분
윅스(Wix), 임웹 등본격적인 홈페이지·쇼핑몰 빌더, 다양한 템플릿과 기능 제공정식 사업자 홈페이지·쇼핑몰을 만들려는 분
프레이머(Framer) 등세련된 디자인, AI 텍스트/이미지 생성 기능 내장디자인 완성도를 중요하게 생각하는 분
구글 사이트 도구완전 무료, 매우 간단한 구조. 구글 계정만 있으면 바로 시작가장 간단한 소개 페이지가 필요한 입문자

3. AI 코딩 어시스턴트로 직접 만들기

Claude, ChatGPT 같은 AI 코딩 어시스턴트에게 원하는 홈페이지를 설명하면, 실제로 동작하는 HTML/CSS 코드를 만들어줍니다. 완성된 코드를 저장해서 바로 브라우저에서 열어볼 수 있습니다.

홈페이지 제작 요청 프롬프트 예시동네 베이커리를 위한 1페이지짜리 홈페이지를 HTML/CSS로 만들어줘. 구성: 상단 - 가게 이름과 대표 사진 / 소개 - 가게 스토리 2~3문단 / 메뉴 - 대표 메뉴 4개를 카드 형식으로 / 하단 - 영업시간, 위치, 전화번호, 인스타그램 링크. 색상은 따뜻한 베이지·브라운 톤으로, 모바일에서도 잘 보이게 반응형으로 만들어줘.

AI가 만들어준 코드는 텍스트 파일로 저장한 뒤 .html 확장자로 바꿔 저장하면 바로 더블클릭으로 열어볼 수 있습니다. 마음에 안 드는 부분은 "메뉴 카드 색상을 더 밝게 바꿔줘"처럼 AI에게 계속 이어서 수정 요청하면 됩니다.

💡 팁: 처음부터 완벽하게 요청하려 하지 말고, 뼈대를 먼저 만든 뒤 "이 부분만 수정해줘" 식으로 조금씩 다듬어가는 것이 훨씬 효율적입니다. (3장에서 배운 "단계별 지시" 기법을 활용하세요.)

4. 도메인과 호스팅 기초

홈페이지를 완성했다면, 다른 사람들도 접속할 수 있게 인터넷에 올려야 합니다.

  • 도메인(Domain): "www.내가게.com" 같은 인터넷 주소. 도메인 등록 대행 서비스에서 연 단위로 구매
  • 호스팅(Hosting): 내가 만든 홈페이지 파일을 저장해 인터넷에 항상 떠 있게 해주는 서버 공간
  • 무료로 시작하는 방법: 코드 공유·배포 플랫폼(예: 깃허브 페이지 등)을 활용하면 완전 무료로 간단한 홈페이지를 인터넷에 올릴 수 있습니다.
  • 노코드 툴을 사용했다면 대부분 자체 호스팅이 포함되어 있어 별도 설정 없이 "게시" 버튼만 누르면 됩니다.

✏️ 실습: 나만의 소개 페이지 만들기

  1. 노코드 툴 또는 AI 코딩 어시스턴트 중 하나를 선택합니다.
  2. 내 가게, 취미, 또는 개인 소개 페이지를 목표로 정합니다.
  3. AI 코딩 어시스턴트를 선택했다면, 위 예시처럼 구성·색상·톤을 구체적으로 담아 요청합니다.
  4. 완성된 결과물을 실제로 열어보고, 마음에 안 드는 부분을 AI에게 이어서 수정 요청합니다.
  5. 가능하다면 무료 호스팅 서비스를 이용해 실제로 인터넷에 게시해봅니다.

✅ 핵심 요약 체크리스트

  • 노코드와 AI 코딩, 두 제작 방식의 장단점을 이해했다
  • 목적에 맞는 노코드 툴을 선택할 수 있다
  • AI 코딩 어시스턴트에게 구체적인 프롬프트로 홈페이지 코드를 요청할 수 있다
  • 도메인·호스팅의 기본 개념을 이해했다
